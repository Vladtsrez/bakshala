# 🏕️ Бот Ранчо Бакшала

Telegram-бот для Ранчо Бакшала — інформація про риболовлю, будинок, альтанку та бронювання.

---

## 🚀 Деплой на Railway (покрокова інструкція)

### 1. Завантаж файли на GitHub
- Створи новий репозиторій на [github.com](https://github.com)
- Завантаж три файли: `bot.py`, `requirements.txt`, `Procfile`

### 2. Задеплой на Railway
1. Зайди на [railway.app](https://railway.app) → **New Project**
2. Обери **Deploy from GitHub repo**
3. Підключи свій GitHub і вибери репозиторій
4. Railway автоматично встановить залежності

### 3. Додай змінну оточення (важливо!)
У Railway → Settings → Variables додай:
```
BOT_TOKEN = 8892137618:AAF5J5FGL2TN19R5NTEXMIZTSNI7LNUc
```
*(Токен вже вшитий у код як fallback, але через змінну — безпечніше)*

### 4. Перевір деплой
- Перейди у вкладку **Deployments** — статус має бути **Active**
- Відкрий Telegram і напиши боту `/start`


---

## ✏️ Як редагувати тексти

Всі тексти знаходяться у `bot.py` у секції **"Тексти"**:
- `WELCOME_TEXT` — привітання при /start
- `FISHING_TEXT` — умови риболовлі
- `HOUSE_TEXT` — умови проживання
- `GAZEBO_TEXT` — умови альтанки
